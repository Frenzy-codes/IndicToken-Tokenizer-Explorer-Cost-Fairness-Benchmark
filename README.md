# IndicToken-Tokenizer-Explorer-Cost-Fairness-Benchmark
IndicToken evaluates how LLM tokenizers (GPT-2, GPT-4o, BERT, XLM-R, MuRIL) split English, Hindi &amp; Marathi text. It demonstrates how BPE, WordPiece &amp; SentencePiece fragment Devanagari into byte fallbacks, causing a 3.8×–5.5× cost inflation and 80% context loss. Features FastAPI, Groq LLM/Whisper, and a Google Stitch UI.
